# 好好 · 老人端用药管理

面向需要长期服用一种或多种药物的居家老人，支持老人自主使用和家属协助管理，并通过字号调整、语音朗读与高亮降低阅读和操作负担。

- **今日**：用药任务与进度、用药及漏服确认、撤销、用药记录、联系家属。
- **计划**：新增、编辑和删除用药计划，设置时间、重复日程、药品、每日频次与单次剂量。
- **我的**：个人资料、常用药与联系人管理、用药提醒、字号设置。
