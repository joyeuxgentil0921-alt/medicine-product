# Figma 分享与 GitHub 发布说明

## 推荐的展示方式

以 GitHub Pages 上的 HTML 演示作为公开体验入口，同时提供 Figma 原型、全部原图和教程视频。GitHub 保存原始文件，Pages 负责把 HTML 作为网页运行。

## 让 Figma 原型无需逐一申请

1. 在 Figma 编辑文件中选择「今日」起始页面，点击右上角 Present（播放）。
2. 在原型播放窗口点击 Share prototype（分享原型）。
3. 将 Who has access（谁可以访问）设置为 Anyone（任何人／任何拥有链接的人）。
4. 将访问级别设为 Can view（可以查看）。不需要给体验者编辑权限。
5. 如果有密码或链接到期限制，按展示需求调整；组织强制的规则需要管理员处理。
6. 复制原型链接，使用未登录 Figma 的浏览器无痕窗口测试：应直接显示原型，且可以点击交互，不出现申请访问。
7. 验证通过后，将链接更新到 README 和素材总览页。

已记录的原型链接：

https://www.figma.com/proto/RF1My8Yh2994z0DMbGgtXi/%E8%80%81%E4%BA%BA%E7%AB%AF?node-id=329-328&t=DBbZBDRZophZvJDR-1

如果没有 Anyone 选项，可能是组织或工作区禁用了公开链接。不能通过把链接放进 GitHub、iframe 或二维码来绕过权限，需要文件所有者或管理员调整。仅分享原型而限制访问完整设计源文件属于付费方案能力；Starter 方案的原型查看者仍可能进入设计文件查看，所以公开前应确认文件中的内容适合公开。

## 上传完整目录

已指定目标仓库：[https://github.com/joyeuxgentil0921-alt/medicine-product](https://github.com/joyeuxgentil0921-alt/medicine-product)。

该仓库已由作者提供，不需要重复创建。建议先在 GitHub Desktop 中选择 File → Clone repository → URL，粘贴上面的地址，再将本发布包内部的材料复制进克隆目录，提交并 Push。

使用 GitHub Desktop 上传到该仓库：

1. 登录 GitHub Desktop。
2. 选择 File → Clone repository → URL，填写 `https://github.com/joyeuxgentil0921-alt/medicine-product`，选择本地保存位置。
3. 将本发布包内部的全部内容复制进克隆出来的仓库目录。不要再套一层「github发布包」文件夹；如仓库已有其他内容，先核对同名文件再替换。
4. 在 Changes 中核对文件，填写提交说明，例如「添加用药助手原型、HTML 演示与教程」，点击 Commit to main。
5. 点击 Push origin；如果你当前使用的账户没有写入权限，需要切换为仓库所有者或获得仓库授权。
6. 在 GitHub 网页中确认根目录有 `index.html`、`README.md`、`prototypes` 和 `videos`。
7. 按 README 的 Pages 步骤开启在线演示。

当前发布包只包含新版操作演示 `videos/tutorial.mp4`，约 16.26 MiB、60 秒，由最新的「操作演示.mov」通过 Passthrough 重新封装。原 MOV 保留本机，避免重复上传相同视频。旧的大视频及旧播放副本均不包含在发布包或本次上传记录中。

也可以通过 GitHub 网页上传：

1. 打开指定仓库，空仓库时点击 uploading an existing file；已有文件时选择 Add file → Upload files。
2. 将本发布包解压后的文件和文件夹拖入上传区。新版视频小于网页单文件 25 MiB 限制。
3. 检查根目录直接包含 `index.html`、`README.md`、`materials.html`、`prototypes` 和 `videos`。
4. 填写提交说明并提交到 main。
5. 在 Settings → Pages 中选择 Deploy from a branch → main → /(root)，保存。


## 发布后的检查

- 无痕窗口打开 Pages 首页，可以操作今日、计划和我的页面。
- 打开 `materials.html`，图片能加载，教程能播放。
- 无痕窗口打开 Figma 原型链接，不出现申请权限。
- README 内更新实际 Pages 地址，仓库 About 的 Website 字段也填写该地址。
- 新版原型图或 HTML 更新后，替换相应文件并提交；Pages 会重新发布。
